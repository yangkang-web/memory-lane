# 回忆之路：最后一次并肩 — 60 秒第一视角剪辑

当前版本保留用户指定的“坍塌 → 断臂 → 地铁逃生”，删去支线，重新编排连续路线。小月始终是随身终端里的声音。

| 播放时间 | 剧情与节奏 |
| --- | --- |
| 0–5 秒 | 看向日葵，抬起终端听到“我在”，走出屋子。平静开场。 |
| 5–12 秒 | 看街道与废墟，听到异响，转头发现感染者。留出观察时间。 |
| 12–18 秒 | 转身逃跑，抬头看见巨型变异体从高处坠落；砸裂路面，主角随坍塌坠入地铁，短暂失去意识。突然提速。 |
| 18–23 秒 | 慢慢苏醒，低头发现手臂被压。“我在，先别乱动。”镜头基本停住。 |
| 23–32 秒 | 拿到撬棍，稳定用力撬梁；听到“小心”，发生二次坍塌。蓄力后突变。 |
| 32–39 秒 | 发现失去左前臂，撕裂袖口与带血伤口可见；短暂反应后直接拾杆起身，不再包扎。 |
| 39–52 秒 | 单臂逃生：地铁昏暗，追兵奔跑逼近；躲开扑击，绕过检修室墙角穿门，关门后跑上楼梯。 |
| 52–60 秒 | 感染者从远处持续冲向楼梯口，主角坐下抬起终端，说“你别关机”；58.2 秒黑场，“听得到吗？”结束。 |

删除：商店搜集、镜中发现感染者、商店搏斗、街头包扎与连续翻越、反复撞门、原版结尾巨型感染者、抽烟。路线从邻近坍塌路面的居所出发，结尾停在地铁楼梯口，避免为走完长距离而加速镜头。

镜头沿重新编排的空间路径连续运动。动作素材按各段的需要单独分配时间；7 句本地对白均以原速播放。进度条、章节、音效、暂停、重播与结束均以 60 秒播放时间为准。回退恢复相应伤势和道具状态；退出后恢复原来的自由漫游地图。

实现：`src/last-companion-edit.js` 定义剪辑、镜头路线、对白与音效。`last-companion-timeline.js` 的 480 秒只作为既有动作素材坐标。旧长篇分镜保留在 `last-companion-source-storyboard.md`，不代表当前播放内容。
