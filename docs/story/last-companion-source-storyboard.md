# 回忆之路：最后一次并肩 — 第一视角分镜

总长 480 秒，8 章 × 60 秒。章节分界不重置世界状态；可从头连续自动观看，也可选择章节重看。小月始终存在于随身终端中，没有实体同伴。对白、回忆录音与环境音分轨，字幕保留原文。所有镜头由主角双眼位置出发，手、衣袖、道具和动作反馈在同一三维空间内呈现。

## 01｜重逢（总时间 00:00–01:00）

| 章内时间 | 第一视角画面与动作 | 台词 / 声音 |
|---|---|---|
| 0–7 | 从《向日葵》移向屋顶漏点，雨滴落入凹陷的铁盆，水面起小涟漪；低头看剩余物资。 | 滴水、屋外小雨、衣料摩擦。 |
| 7–15 | 右手翻过空罐头；把半瓶水装进敞开的背包，背包挂回肩上。 | 金属空响、塑料瓶声、拉链。 |
| 15–24 | 桌角旧终端闪亮。拾起终端，拇指擦去屏幕灰尘，另一只手拿出随身电源，接上短电缆。 | 电流轻响、接头接触不良。 |
| 24–33 | 接头往左压，屏幕波形稳定。手在听见声音时停住，视线定在“小月”名字上。 | 小月：“往左压一点。以前就是这样。” 我：“小月？” 小月：“嗯。听得到。” |
| 33–42 | 将终端放进胸袋，拿起门边旧铁管；手掌推开破木门。 | 衣袋摩擦、铰链吱响。 |
| 42–52 | 跨门槛下台阶，暗室过渡到灰白晨雾；扫过草中废车和松动的店铺招牌。 | 风、独自脚步。 |
| 52–60 | 沿街走向便利店，门内昏暗，手电打开。 | 我：“先找吃的。” 小月：“街角那家便利店，你以前经常去。” |

## 02｜玻璃里的眼睛（01:00–02:00）

| 章内时间 | 第一视角画面与动作 | 台词 / 声音 |
|---|---|---|
| 0–12 | 通过敞开的店门，沿货架寻找；依次拿走两瓶水。被取走的物品不再留在货架上。 | 门铃残响、脚踩碎屑。 |
| 12–22 | 拿走绷带和未拆封压缩饼干，装入背包。 | 包装纸、拉链。 |
| 22–31 | 视线停在柜台边褪色柠檬糖上；拿到眼前；终端亮起旧录音波形。 | 旧录音：“说好了，以后我们是一队的。” |
| 31–39 | 轻微呼吸停顿，镜头向冷柜转去。店员制服感染者背对主角，额头抵玻璃。 | 小月：“里面有人。” |
| 39–48 | 举手电向前一步，光束照出肩膀和玻璃；玻璃中的浑浊双眼看向主角，身体仍静止。 | 冷柜低频电噪、呼吸。 |
| 48–55 | 主角停步、慢慢后退。倒影中的目光随位置偏移，背影不动。 | 我：“小月？” 小月：“慢慢退。” |
| 55–60 | 身后衣料声；突然回头，一张感染者脸贴近镜头，扑击开始。 | 布料擦动、短促吸气、扑击声。 |

## 03｜入口被封死（02:00–03:00）

| 章内时间 | 第一视角画面与动作 | 台词 / 声音 |
|---|---|---|
| 0–9 | 被撞向货架，镜头后仰；铁架倾倒、瓶子落地碎裂。双手横起铁管挡住感染者，牙齿在手腕旁咬合。 | 撞击、玻璃、铁管与牙齿碰撞。 |
| 9–19 | 膝顶后推开；第一次挥管将其撞向柜台；其挣扎起来，第二次击倒。 | 两次独立挥击和身体落地。 |
| 19–26 | 冷柜刮擦，店员感染者缓慢转头。正门撞碎，数个感染者越过碎玻璃进入。 | 玻璃刮擦、门爆裂、尸群。 |
| 26–34 | 镜头扫过被挤满的入口，再回向后场。 | 我：“后门！” 小月：“穿过仓库，右边！” |
| 34–43 | 挥管迎击，第二下衣袖被抓；撞货架甩开，踹倒前方感染者，越过柜门。 | 抓扯、柜体碰撞。 |
| 43–51 | 背包突然被扯住，镜头猛退；回身用背包砸开抓手，再以铁管逼退。 | 肩带绷紧、背包撞击。 |
| 51–60 | 侧面扑击，将肩膀擦向破橱窗；镜头剧烈偏转，袖口出现暗红浸湿；冲进仓库。 | 衣料撕裂、疼痛呼吸、紧逼脚步。 |

## 04｜血迹（03:00–04:00）

| 章内时间 | 第一视角画面与动作 | 台词 / 声音 |
|---|---|---|
| 0–9 | 两次拉后门把手，门不动；回看追兵撞开仓库货架。 | 把手两次空响。 |
| 9–16 | 小月提示后蹲下，右手抽开低位插销，用肩膀顶门。 | 小月：“下面的插销！” 插销滑动。 |
| 16–25 | 跨出后脚踝被抓，摔入积水、被拖回；终端发尖锐警报，抓手松开，转身踹开。 | 落水、拖拽、警报、踢击。 |
| 25–34 | 爬起，将有轮垃圾箱推倒挡门，门板随撞击鼓动；沿巷奔跑，袖口血滴融进水中。 | 滚轮、箱体倒地、闷撞。 |
| 34–45 | 扶废车停下，撕开绷带。手抖、绷带滑落，重新拾起并压住肩伤。 | 小月：“先压住伤口。” |
| 45–53 | 巷口感染者停住、伏低，鼻尖靠近积水里的血迹，背部逐渐绷紧。 | 嗅闻、短促喘息。 |
| 53–60 | 感染者抬头长啸；窗后身影、车库脚步、卷帘门撞击、屋顶攀越依次响应。绷带扯紧。 | 长啸扩散；小月：“跑！” |

## 05｜脚下的黑暗（04:00–05:00）

| 21–30 | 右侧玻璃炸裂，一个感染者扑出，手指擦过后背；视角避让再恢复前进。 | 玻璃、近身抓挠。 |

| 54–60 | 主角作出最后选择，抬头瞬间切黑，不展示装置结构或操作细节。呼喊与爆响后只剩耳鸣。 | 小月急切呼喊；黑暗中：“……听得到吗？” 无回答。 |

## 持续状态与制作验收

- 左肩受伤：第 3 章末发生，第 4 章包扎；血迹触发感染者行为，不是无关地面贴花。
- 左前臂缺失：第 6 章 41 秒后持续至结尾；手臂模型、道具持握、动作和阴影同时更新。
- 背包：第 1 章装包，第 2 章搜刮，第 3/4 章被扯，第 7 章丢失；不能在后续重新出现。
- 终端：积尘 → 开机 → 胸袋 → 旧录音 → 警报 → 裂屏 → 广场放下 → 黑暗余音。
- 不出现旧剧情中的实体同伴林、步枪、车底钻行或“暂时安全”结局。
- 便利店镜中目光、落物、破门、两次坍塌、伤后单手动作、三次撞栅门必须通过实际画面确认，不能仅由字幕代替。
- 每章验证：从前章连续进入、章节跳转、暂停继续、重播复位、退出恢复漫游、浏览器错误检查。完整 480 秒观看与独立评审为最终验收。
