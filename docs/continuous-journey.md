# 连续回忆 /journey

本地独立演示，主入口 `/journey`。原场景仍可独立访问；嵌入模式通过同源 iframe 的 `sequence=1` 开启，不改存档。

| 场景 | 演出 | 后续转场 |
| --- | ---: | --- |
| Emochi 首页年度回忆弹窗，微缩小屋旋转与模拟手点击 | 11 秒 | 2.2 秒穿门光晕，进入小屋 |
| 海边小屋藏品柜，凝视爱心项链 | 12 秒 | 3.8 秒折射裂隙，细丝发光、镜像位移、粒子 |
| Bloodbound | 60 秒 | 4.4 秒门光径向晕开并推近，教室从光心浮现 |
| 学校向日葵故事 | 60 秒 | 5.1 秒现有白墙对角碎裂，同幅画构图匹配 |
| 末世 | 60 秒 | 3 秒灰烬消散至谢幕舞台 |
| 谢幕 /stage（Emochi 谢幕） | 30 秒 | 停留在结束卡，不自动循环 |

总设计时长 251.5 秒，资源等待与主动暂停不计入。开始前载入前两个场景，之后只预载下一场；过场后主动销毁上一场景，最多两个场景同时存在。开场弹窗展示年度回忆文案；进入小屋后隐藏标题、字幕、HUD、进度条和所有控制；场景里的信纸、手机、标牌仍属于剧情道具。Esc 暂停/继续，切出页面暂停。音频和模型缺失显示可重试错误，不能静默跳过。

吸血鬼原版是交互推进；串联版由自动驾驶从危机开场，按墙钟卡满 60 秒：危机 0–9、救援 9–16、伤口 16–24、亲密 24–44、信物与佩戴 44–56（加快节奏，台词不删）、56–60 转身双手推开礼拜堂门，暖光涌入。后台预载下一场造成的长帧会分成 0.1 秒小步补回，避免拖长。独立 `/bloodbound` 仍是完整交互版。

学校结尾串联模式收起信纸，朝墙上既有梵高《向日葵》调整视线与焦距；原白墙转场 `world-fracture.js` 直接合成学校结尾和末世开头的实时渲染截帧。其他转场也使用真实两端画面，不加载外部视频素材。开启系统减少动态效果时采用柔和溶解。

## 年度回忆开场

首页使用 2026-10-15 从 emochi.com 浏览器截取的本地静态背景，位于 public/assets/journey/emochi-home.jpg，不接入真实首页或用户年度统计。弹窗、小屋、星屑及手势在本项目渲染。小屋为原创 Three.js 微缩建筑，7 秒前模拟点击，先对正门洞再向内推进。用户也可直接点小屋或按钮提前进入。首次点击“播放年度回忆演示”启用浏览器音频。

推门的冲击发生在吸血鬼场景内（门扇甩开、低频气浪、镜头轻震）；随后 4.4 秒转场从门后光源径向晕开并推近，画面短暂化为暖白，学校首帧从光心以 1.15→1.0 的比例浮现，配低频涌起和一个柔和和弦，不做硬切。末尾 /stage 为 `codex/emochi-curtain-call` 带来的 30 秒 Emochi 谢幕：串联模式隐藏开始页和播放控制，保留字幕和结束卡，30 秒发送完成。五颗回忆球对应旅程中的教室、海边小屋、末世「我在」、月下教堂和年度回忆小屋。旧 /blank 地址仍是原临时星光舞台。
