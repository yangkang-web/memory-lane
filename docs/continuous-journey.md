# 连续回忆 /journey

本地独立演示，主入口 `/journey`。原场景仍可独立访问；嵌入模式通过同源 iframe 的 `sequence=1` 开启，不改存档。

| 场景 | 演出 | 后续转场 |
| --- | ---: | --- |
| Emochi 首页年度回忆弹窗，微缩小屋旋转与模拟手点击 | 11 秒 | 2.2 秒穿门光晕，进入小屋 |
| 海边小屋藏品柜，凝视爱心项链 | 12 秒 | 3.8 秒折射裂隙，细丝发光、镜像位移、粒子 |
| Bloodbound | 约 68 秒 | 4.4 秒门光径向晕开并推近，教室从光心浮现 |
| 学校向日葵故事（含自动聊天与拆信序章） | 约 59.05 秒 | 5.1 秒现有白墙对角碎裂，同幅画构图匹配 |
| 末世 | 60 秒 | 3 秒灰烬消散至谢幕舞台 |
| 谢幕 /stage（Emochi 谢幕） | 30 秒 | 停留在结束卡，不自动循环 |

总设计时长约 258.55 秒（4 分 19 秒），资源等待与主动暂停不计入。开始按钮可用前载入全部场景（约 11 秒）；过场后主动销毁上一场景。开场弹窗展示年度回忆文案；进入小屋后隐藏标题、HUD、进度条和所有控制；台词字幕保留（含海边项链独白），末世场景的中文字幕与吸血鬼字幕同一样式（小号说话人加衬线台词，不加英文）；场景里的信纸、手机、标牌仍属于剧情道具。Esc 暂停/继续，切出页面暂停。音频和模型缺失显示可重试错误，不能静默跳过。

吸血鬼原版是交互推进；串联版由自动驾驶完整播放，约 68 秒：先沿中殿走向祭坛，再经危机、救援、伤口、亲密、信物与佩戴（信物与佩戴略加快，台词不删、字幕保留），最后转身双手推开礼拜堂门，暖光涌入。串联里预载时停在首帧（起点机位与播放时同一层暗角），转场揭开的就是开始走动的那一帧，不再先露出标题画面再跳一次；暂停时画面完全静止。独立 `/bloodbound` 仍是完整交互版。

所有场景在开始按钮可用前一次性载入：各世界共用一个主线程，边播边载会让正在播放的场景卡住数秒。尚未轮到的场景每秒只画几帧（`sequence-bridge.js`），把 GPU 留给当前场景。

学校结尾串联模式收起信纸，朝墙上既有梵高《向日葵》调整视线与焦距；原白墙转场 `world-fracture.js` 直接合成学校结尾和末世开头的实时渲染截帧。其他转场也使用真实两端画面，不加载外部视频素材。开启系统减少动态效果时采用柔和溶解。

## 年度回忆开场

首页使用 2026-10-15 从 emochi.com 浏览器截取的本地静态背景，位于 public/assets/journey/emochi-home.jpg，不接入真实首页或用户年度统计。弹窗、小屋、星屑及手势在本项目渲染。小屋为原创 Three.js 微缩建筑，7 秒前模拟点击，先对正门洞再向内推进。用户也可直接点小屋或按钮提前进入。首次点击“播放年度回忆演示”启用浏览器音频。

推门的冲击发生在吸血鬼场景内（门扇甩开、低频气浪、镜头轻震）；随后 4.4 秒转场从门后光源径向晕开并推近，画面短暂化为暖白，学校首帧从光心以 1.15→1.0 的比例浮现，配低频涌起和一个柔和和弦，不做硬切。末尾 /stage 为 `codex/emochi-curtain-call-encore` 带来的 30 秒 Emochi 谢幕：Emochi 从幕布后探头致谢，五颗回忆球是团队制作中的熬夜、改稿、重试、再来一条和难关。串联模式隐藏开始页和播放控制，保留标题、字幕和结束卡（不含来源说明），30 秒发送完成。旧 /blank 地址仍是原临时星光舞台。


## 学校段与独立剧情同步

`/journey` 与 `/school` 共用同一个学校播放器、自动开场和场景，包含最新人物表演、第一人称手部、蜡封信封、拆信、镜头景深以及窗内飘花。学校段先自动播放约 29.46 秒的聊天与递信开场，再播放约 29.59 秒的精剪音轨，完整保留读信、告白和画作结尾；剪辑时间映射到原始镜头与口型时间线，不会重复旧开场或提前切走。设计时长由共享常量计算。

预载只准备资源，不提前播放。序章和读信阶段均响应串联播放器的 Esc 暂停/继续；只有最后音轨结束才通知下一场。向日葵画作末帧通过同一景深渲染管线截取，并在离开学校时释放后处理资源。串联版收起结尾手持信纸，保持白墙碎裂转场的画作构图；独立学校剧情仍保留原有控制和结尾。
